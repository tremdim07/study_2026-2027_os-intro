# Теоретическое введение

Bash - командная оболочка и язык программирования, широко используемый в Unix-подобных системах. Скрипт начинается с shebang (`#!/bin/bash`). Переменные не требуют явного объявления типа, их значения хранятся как строки. Доступ к аргументам скрипта осуществляется через `$1`, `$2`, ..., `$#` (количество аргументов). Условные операторы `if` проверяют код возврата команд или выражения `[[ ]]`. Циклы `for` и `while` позволяют автоматизировать повторяющиеся действия. Функции определяются синтаксисом `func() { ... }`. Для поиска файлов используется `find`, для фильтрации текста - `grep`, для потокового редактирования - `sed`. Визуализация данных возможна с помощью `gnuplot`. Текстовый редактор `vim` имеет режимы: нормальный, вставки, визуальный. Понимание этих инструментов необходимо для эффективной работы в командной строке.
